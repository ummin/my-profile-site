# 발악하는날다람쥐 | 포트폴리오

10년차 풀스택 개발자의 포트폴리오 사이트입니다.

## 파일 구조

- **index.html** - 메인 HTML 마크업 파일
- **style.css** - 스타일시트 (글로벌 스타일, 애니메이션, 반응형 디자인)
- **main.js** - JavaScript 로직 (프로젝트 필터링, 인터랙션, 애니메이션 제어)
- **README.md** - 이 파일

## 실행 방법

1. 프로젝트 폴더를 열기
2. `index.html` 파일을 브라우저에서 열기 (더블 클릭 또는 우클릭 > 열기)
3. 포트폴리오 사이트가 표시됨

## 외부 의존성

- **Tailwind CSS** - CDN을 통한 유틸리티 CSS 프레임워크
- **Google Fonts** - Noto Sans KR (한글 폰트)

## 주요 기능

- **프로젝트 필터링** - 카테고리별 프로젝트 필터 (전체/운영·유지관리/구축/홈페이지)
- **스크롤 애니메이션** - IntersectionObserver를 이용한 등장 애니메이션
- **스킬 바 애니메이션** - 스크롤 시 동적으로 채워지는 숙련도 바
- **반응형 디자인** - 모바일/태블릿/데스크탑 모두 지원
- **모바일 메뉴** - 스마트폰에서 햄버거 메뉴로 네비게이션 제공
- **이메일 복사** - 클릭으로 이메일 주소 클립보드에 복사
